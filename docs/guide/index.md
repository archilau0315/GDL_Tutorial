# 学习路径

GDL_Tutorial 的完整学习路径分三个部分、共 19 章（GDL-00 ~ GDL-18），从零基础到专业级。每章固定结构：**本章目标 → 概念讲解 → 分步示例 → 常见坑 → 沙盒练习**。

## 路线图

| 部分 | 编号 | 内容 | 状态 |
|---|---|---|---|
| 第一部分 · 入门篇 | GDL-00 ~ 05 | 认识 GDL、基本体、变换堆栈、参数化、2D 脚本、控制流 | ✅ 已完成（双语） |
| 第二部分 · 进阶篇 | GDL-06 ~ 12 | PRISM 族、旋转放样、材质、宏、门窗对象、字符串、实战 | ✅ 已完成（双语） |
| 第三部分 · 精通篇 | GDL-13 ~ 18 | UI 脚本、布尔与热区、REQUEST 与 GLOB、数据与文件、工具链、毕业实战 | ✅ 已完成（双语） |

## 怎么学

1. 按章节顺序走，别跳——尤其第 2 章变换堆栈，是 GDL 最核心的心法
2. 每个示例在沙盒里亲手改一遍参数，看变化
3. 学完一章回 Archicad 里照着做一次真实对象，才算过关
