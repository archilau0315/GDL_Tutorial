# 第 1 章 第一个 3D 对象

> 图号 GDL-01 · 入门篇 · 阅读约 20 分钟 · 含沙盒练习

## 本章目标

- 掌握四个 3D 基本体及其**参数顺序**
- 学会用变量组织尺寸，而不是把数字写死在命令里
- 搭出一个桌凳组合，理解「一个对象 = 若干基本体 + 位置」

## 四个基本体

GDL 的 3D 世界由基本体拼出来。入门只需要四个：

```gdl
BLOCK 1, 2, 0.9      ! 长方体：x 长, y 宽, z 高
CYLIND 1.2, 0.4      ! 圆柱：高, 半径
SPHERE 0.5           ! 球：半径
CONE 1.2, 0.5, 0.1   ! 圆锥：高, 底半径, 顶半径（顶半径为 0 即尖顶）
```

三个必须记住的点：

1. 都从**当前原点**沿正方向生长（不是从中心）
2. **Z 是高度**，写在最后一个参数
3. `CYLIND` 和 `CONE` 的**第一个参数是高度**，不是半径——这是错得最多的地方

::: warning CYLIND 为什么容易错
多数软件的圆柱是 `radius, height`，GDL 反着来：`CYLIND h, r`。写成 `CYLIND 0.4, 1.2` 会得到一根 0.4 高、1.2 粗的矮胖墩。
:::

## 从写死数字到用变量

直接写数字能做东西，但改不动。第一件事就是把尺寸提成变量：

```gdl
w  = 1.2    ! 宽
d  = 0.6    ! 深
h  = 0.72   ! 高
th = 0.04   ! 板厚
```

变量名大小写不敏感，习惯上小写。**变量 = 参数化的第一步**：在真实 Archicad 对象里，这些变量就是参数面板上的参数（第 3 章展开）。

## 搭桌子：桌面 + 四条腿

思路很朴素：先放桌面，再把原点挪到每条腿的位置放圆柱。

```gdl
w = 1.2
d = 0.6
h = 0.72
th = 0.04
legR = 0.03

! 桌面：抬到 h - th 的高度
ADD 0, 0, h - th
BLOCK w, d, th
DEL 1

! 四条腿：靠双层循环
FOR i = 1 TO 2
  FOR j = 1 TO 2
    ADD legR + (i - 1) * (w - 2 * legR), legR + (j - 1) * (d - 2 * legR), 0
    CYLIND h - th, legR
    DEL 1
  NEXT j
NEXT i
```

这段代码里有三件新东西：`ADD`（移动原点）、`DEL 1`（撤销这次移动）、`FOR`（循环）。**它们都在第 2 章和第 5 章细讲**，现在先照抄跑通，建立手感。

## 试一试

下面沙盒就是上面这段代码（外加一个独腿凳）。动手改三处，观察变化：

2. 把 `legR = 0.03` 改成 `0.06`——腿变粗，位置也跟着调整
3. 把某一行 `DEL 1` 删掉——后面的几何体全部跑偏，并可能出现报错

## 常见坑

::: warning 这一章最容易错的四处
1. **参数顺序**：`CYLIND h, r`、`CONE h, r1, r2`，高度永远在前
2. **忘了 DEL**：`ADD` 之后不 `DEL`，原点停在原地，后面所有东西都跟着漂移
3. **尺寸自相矛盾**：腿半径比桌宽还大，几何体会穿模甚至报负值错误
4. **单位混用**：把 720 当成 720mm 写进去，模型直接飞走
:::

## 练习

1. 给桌子加一圈横撑：在高度 0.2m 处，用 `BLOCK` 连接四条腿（提示：用循环 + `ADD`）
2. 把桌腿从圆腿改成方腿（`BLOCK` 代替 `CYLIND`），尺寸 `2*legR × 2*legR`
3. 把桌子改成"吧台"：高度 1.05m，桌面厚度 0.06m，看看腿要不要改

参考答案思路：横撑就是把原点挪到腿的位置，然后画一根长条；关键是**别忘了画完 `DEL`**。
