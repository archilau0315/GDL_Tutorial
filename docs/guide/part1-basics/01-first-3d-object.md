# 第 1 章 第一个 3D 对象

> 图号 GDL-01 · 入门篇 · 沙盒已嵌入，本章可用交互方式练习

本章你将用 `BLOCK`、`CYLIND`、`SPHERE`、`CONE` 四个基本体，加上固定参数 `A`、`B`、`ZZYZX`，搭出第一个参数化桌凳。

## 基本体一览

```gdl
BLOCK 1, 2, 0.9      ! 长方体：x 长 × y 宽 × z 高
CYLIND 1.2, 0.4      ! 圆柱体：高， 底半径
SPHERE 0.5           ! 球体：半径
CONE 1.2, 0.5, 0     ! 圆锥：高， 底半径， 顶半径（0 为尖顶）
```

::: warning 坐标系提醒
GDL 坐标系 X/Y 为水平面，**Z 轴向上**——与 Archicad 一致；基本体都从当前原点起生成。
:::
