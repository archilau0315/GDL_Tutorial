# 第 1 章 第一个 3D 对象

> 图号 GDL-01 · 入门篇 · 编写中（P2 阶段完成全文，沙盒将在此章亮相）

本章你将用 `BLOCK`、`CYLIND`、`SPHERE`、`CONE` 四个基本体，加上固定参数 `A`、`B`、`ZZYZX`，搭出第一个参数化桌凳。

## 基本体一览

```gdl
BLOCK 1, 2, 0.9      ! 长方体：x × y × z
CYLIND 0.4, 1.2      ! 圆柱体：底半径 × 高
SPHERE 0.5           ! 球体：半径
CONE 0.5, 2, 0       ! 圆锥：底半径 × 高 × 顶半径
```
