# 第 0 章 认识 GDL

> 图号 GDL-00 · 入门篇 · 阅读约 12 分钟

## 本章目标

- 说清 GDL 是什么、能做什么、值不值得学
- 认识库部件（.gsm）的内部结构：六种脚本各管什么
- 建立第一个关键认知：**GDL 的坐标系 Z 轴向上**
- 知道在 Archicad 里从哪儿动手，以及沙盒与真实环境的对应关系

## GDL 是什么

GDL（Geometric Description Language，几何描述语言）是 Graphisoft 为 Archicad 设计的参数化建模语言。你用几十行文字描述一个对象，Archicad 按参数实时生成它的三维模型和平面符号。

写 GDL 的收益很直接：

1. **造零件**：Archicad 图库里没有的门窗、家具、构件，你自己造
2. **一次编写，处处复用**：一个参数化书架，改参数就是另一个书架
3. **进 BIM 数据流**：对象自带工程量、材质、属性，能进明细表
4. **理解 Archicad 的底层**：看懂图库对象怎么工作，很多「玄学」问题自然通了

对建筑师来说，GDL 是把设计意图固化成可复用工具的最短路径——比学一门通用编程语言直接得多。

## 库部件里有六个脚本

一个 `.gsm` 图库对象不是一个文件里塞一段代码，而是分脚本存放，各管一段：

| 脚本 | 什么时候跑 | 管什么 |
|---|---|---|
| 主脚本 Master | 最先跑，其余脚本之前 | 公共计算、参数预处理，结果供其他脚本使用 |
| 参数脚本 Parameter | 参数变化时 | 参数联动、取值约束（如「高度不超过 3 米」） |
| 2D 脚本 | 画平面图时 | 平面符号：线条、填充、文字 |
| 3D 脚本 | 三维视图时 | 生成模型本体 |
| 属性脚本 Properties | 算量时 | 组件、表面、工程量分类 |
| UI 脚本 | 打开参数面板时 | 自定义参数界面布局 |

**入门阶段只需要盯住 3D 脚本和 2D 脚本**。其余四种是进阶内容，后续章节逐个展开。

::: tip 运行顺序
主脚本 → 参数脚本 → 2D/3D 脚本。这也是为什么公共变量写在主脚本里：它在所有脚本之前算好，2D 和 3D 都能直接用。
:::

## 第一个关键认知：Z 轴向上

GDL 用的是**右手坐标系，Z 轴向上**：

- **X / Y** 是水平面（就是平面图上的两个方向）
- **Z** 是高度，向上为正

这一点和很多 3D 软件（Y 轴向上）不同，也和 Rhino/Grasshopper 的习惯不同。**所有「高度」都写在第三个参数或 Z 方向**，一开始最容易错的就是这里。

原点（0, 0, 0）就是对象在平面图上的插入点，也是 3D 脚本的起点。

## 语法速览：五条规则定全局

```gdl
! 感叹号开头是注释，到行尾结束

a = 1.2          ! 变量：赋值，大小写不敏感（A 与 a 是同一个）
BLOCK a, 2, 0.5  ! 命令：命令名 + 逗号分隔的参数

! 单位：长度米，角度度。0.72 就是 720mm，不是 72cm
```

1. 注释用 `!`
2. 语句**一行一条**，换行即结束
3. 参数用**逗号**分隔；行尾留逗号可以续到下一行
4. 变量与命令**大小写不敏感**（习惯上命令全大写、变量小写）
5. 长度单位是**米**，角度单位是**度**

## 沙盒与真实环境：哪里不一样

本站的在线沙盒跑的是自研 GDL 解释器，覆盖教学范围：

| 项目 | 沙盒 | Archicad |
|---|---|---|
| 3D 脚本 | ✅ 支持 | ✅ |
| 2D 脚本 | ✅ 支持（不含 PROJECT2 投影） | ✅ |
| 参数面板 | ❌ 用变量代替 | ✅ 真实参数 |
| 报错格式 | ✅ 仿 Archicad（脚本 + 行列 + 描述） | ✅ 官方原文 |
| 渲染精度 | 教学级近似 | 精确 |

**结论**：沙盒用来练语法和思维，最终验收在 Archicad 里。沙盒里写顺手的代码，复制进 Archicad 的 3D 脚本窗口基本可直接跑。

## 在 Archicad 里从哪儿开始

1. 打开 Archicad，`文件 → 图库和对象 → 新建图库对象`（或在图库管理器里「新建对象」）
2. 起名、选子类型（一般选「对象」），确定
3. 对象编辑器打开，左边是脚本列表，右边是代码编辑区
4. 选中 `3D 脚本`，写代码，用「检查脚本」按钮看报错
5. `文件 → 另存为` 存成 `.gsm`，或直接在图库中生效

第 20 章会详细讲工具链（LP_XMLConverter、批量转换）；现在只需知道入口在哪。

## 常见坑

::: warning 三个新手必踩
1. **把高度写进第二个参数**：`BLOCK 1, 2, 0.5` 是 1×2 的底面、0.5 高。写成 `BLOCK 1, 0.5, 2` 就是另一个东西了。
2. **单位搞错**：以为写 `720` 是 720mm，实际是 720 米——对象直接飞出天际。
3. **以为对象从中心长**：GDL 基本体从**当前原点**沿正方向生长，不是从几何中心。
:::
