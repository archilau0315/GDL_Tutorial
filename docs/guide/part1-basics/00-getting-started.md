## GDL 是什么

GDL（Geometric Description Language，几何描述语言）是 Graphisoft 的参数化编程语言，用来描述 3D 对象——门、窗、家具、楼梯——以及它们在平面图上的 2D 符号。写 GDL 的人，等于掌握了给 Archicad「造零件」的能力。

## 库部件的六种脚本

| 脚本 | 职责 |
|---|---|
| 主脚本 Master Script | 在其他脚本之前运行，放公共计算 |
| 3D 脚本 | 生成三维模型 |
| 2D 脚本 | 生成平面符号（为空则用 2D 视图窗口的二进制数据） |
| 参数脚本 | 约束与联动参数取值 |
| 属性脚本 | 工程量计算用的组件与描述 |
| UI 脚本 | 自定义参数设置界面 |
