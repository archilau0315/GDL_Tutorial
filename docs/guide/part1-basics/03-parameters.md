# 第 3 章 参数化入门

> 图号 GDL-03 · 入门篇 · 阅读约 25 分钟 · 含沙盒练习

## 本章目标

- 分清**参数**（Archicad 里可调）与**变量**（脚本内计算）
- 会用固定参数 `A`、`B`、`ZZYZX`
- 会用 `IF` 让几何随尺寸自动取舍
- 做出第一个「改一个数、整体自适应」的对象

## 参数 vs 变量

两者在脚本里长得一样，用法也一样，区别在**谁来改**：

| | 参数 Parameter | 变量 Variable |
|---|---|---|
| 谁定义 | Archicad 对象设置面板 | 脚本里赋值 |
| 谁修改 | 用户，选中对象就能改 | 脚本自己 |
| 生命周期 | 存进 .gsm 文件 | 每次重算消失 |
| 典型用途 | 宽、深、高、材质、样式 | 中间结果、循环计数 |

**关键点**：参数在脚本里就是变量名，你直接拿来用就行，不需要声明读取。

## 三个固定参数

新建一个 Archicad 对象，系统自动给三个参数：

| 参数 | 含义 |
|---|---|
| `A` | 宽（X 方向） |
| `B` | 深（Y 方向） |
| `ZZYZX` | 高（Z 方向，仅对象/灯具类） |

所以最小可用的参数化对象就是：

```gdl
BLOCK A, B, ZZYZX
```

改对象设置里的宽深高，模型立刻变。**这是你的第一个参数化对象**——一行代码。

::: tip 沙盒里的替代方案
沙盒没有参数面板，用**变量**代替参数：开头写 `A = 1.2`、`B = 0.6`、`ZZYZX = 0.72`，效果等价。粘回 Archicad 时把这几行删掉即可（那里参数自带值）。
:::

## 自定义参数

除了 A/B/ZZYZX，你可以加任意参数。以书架为例：

| 参数名 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `shelfW` | 长度 | 0.9 | 书柜宽 |
| `shelfD` | 长度 | 0.3 | 书柜深 |
| `shelfH` | 长度 | 1.8 | 书柜高 |
| `boardT` | 长度 | 0.02 | 板厚 |
| `spacing` | 长度 | 0.4 | 层板间距 |

在 Archicad 里：`对象设置 → 参数 → 新建`，类型选「长度」。之后脚本里直接用 `shelfW` 这些名字。

## 用 IF 让几何自动取舍

参数化不只是"尺寸跟着变"，更是"结构跟着变"。比如书架：层数由高度和间距决定，最后剩下的空间不够一层就不该硬塞。

```gdl
z = 0
WHILE z + boardT <= shelfH
  ADD 0, 0, z
  BLOCK shelfW, shelfD, boardT
  DEL 1
  z = z + spacing
ENDWHILE
```

`WHILE` 的判断条件本身就是"够不够放一层"，**层数自动跟随高度**——把 `shelfH` 从 1.8 改到 2.4，层数自动从 4 层变 6 层。

再看一个 `IF` 的例子：宽度小于 0.6m 时只做单开门，否则做双开门。

```gdl
IF A < 0.6 THEN
  doorW = A
  BLOCK doorW, B, 0.04
ELSE
  doorW = A / 2
  BLOCK doorW, B, 0.04
  ADD doorW, 0, 0
  BLOCK doorW, B, 0.04
  DEL 1
ENDIF
```

- `h = 1.8` → `2.4`：层数自动增加

## 参数设计的三个原则

1. **参数只放"用户真的想改"的东西**：宽深高、层数、材质。中间计算量用变量，别塞进参数面板
2. **给默认值和合理范围**：用参数脚本约束（如 `VALUES "shelfH" RANGE [0.6, 2.4]`），第 13 章展开
3. **参数之间允许联动，但不要互相矛盾**：比如板厚 > 层间距，几何会打架

## 常见坑

::: warning 四个典型问题
1. **在 3D 脚本里给参数重新赋值**：会覆盖用户设置，改一次就回不去了
2. **参数名与命令名撞车**：如把参数叫 `BLOCK`，脚本直接崩
3. **忘记参数单位**：长度参数内部就是米，不需要再除 1000
4. **用参数控制"几何是否存在"却没写 IF**：只改尺寸不改结构，出现薄片或重叠
:::
