# 第 5 章 控制流

> 图号 GDL-05 · 入门篇 · 阅读约 25 分钟 · 含沙盒练习

## 本章目标

- 掌握 `IF` 的块式与单行式两种写法
- 用 `FOR` / `WHILE` 处理"重复"和"直到满足条件"
- 用 `GOSUB` 把重复代码收成子程序
- 知道死循环、变量残留这些坑怎么避

## IF：二选一

块式写法，适合多行：

```gdl
IF h > 1.0 THEN
  BLOCK 1, 1, h
ELSE
  BLOCK 1, 1, 1.0
ENDIF
```

单行写法，适合一个动作：

```gdl
IF legR > 0.05 THEN legR = 0.05
```

条件和数学里的写法一样：`=`（相等）、`<>`（不等）、`<`、`>`、`<=`、`>=`，可以用 `AND` / `OR` 组合。

::: warning 相等判断是 `=`，不是 `==`
`IF a = 1 THEN` 正确。写 `==` 会报语法错误。
:::

## FOR：次数已知的循环

```gdl
FOR i = 1 TO 4
  ADD 0.3, 0, 0
  BLOCK 0.05, 0.05, 0.7
  DEL 1
NEXT i
```

三个要点：

1. 变量可以自己命名，`i` 是习惯
2. 加 `STEP` 控制步长：`FOR i = 10 TO 0 STEP -1`（倒着走）
3. **`NEXT` 后面的变量名可写可不写**，但写了更清楚

::: tip 循环变量在循环结束后仍然存在
`FOR i = 1 TO 4 ... NEXT i` 结束后，`i` 的值是 **5**（超出上限后的第一个值）。如果后面还要用 `i`，记得重新赋值。
:::

## WHILE：条件为真就继续

次数不确定时用 `WHILE`：

```gdl
z = 0
WHILE z + 0.02 <= 1.8
  ADD 0, 0, z
  BLOCK 0.9, 0.3, 0.02
  DEL 1
  z = z + 0.4
ENDWHILE
```

**必须自己改条件变量**（这里是 `z`），否则永远出不来——GDL 不会自动递增。沙盒有 10000 次循环保险丝，真实 Archicad 会直接卡死，务必小心。

## GOSUB：把重复代码收起来

当一个动作要用很多次（比如"画一根立柱"），把它写成子程序：

```gdl
FOR i = 1 TO 7
  ADD (i - 1) * 0.5, 0, 0   ! 先挪到第 i 根的位置
  GOSUB 100                 ! 调用：跳到标签 100
  DEL 1                     ! 退回起点，下一轮重新定位
NEXT i
END                ! 主程序到此结束（重要！）

100:               ! 标签：子程序入口
CYLIND 0.95, 0.02
RETURN             ! 返回调用处
```

四条规矩：

1. `GOSUB 100` 跳到标签 `100:`
2. 子程序以 `RETURN` 结束，回到调用点之后
3. **主程序末尾必须写 `END`**，否则会"掉进"子程序里再执行一遍
4. 子程序共享全局变量，可以读写外面的变量

`END` 那条是最容易忘的。忘了它，主程序会顺着往下"掉进"子程序里，白画一份多余的几何；再往下走到 `RETURN` 才会报「RETURN 没有对应的 GOSUB」。补几何比补报错难查得多。

## 嵌套：循环里套循环

桌子四条腿就是两层循环：

```gdl
FOR i = 1 TO 2
  FOR j = 1 TO 2
    ADD (i - 1) * 1.0, (j - 1) * 0.5, 0
    BLOCK 0.05, 0.05, 0.7
    DEL 1
  NEXT j
NEXT i
```

**内层循环变量名不能和外层重名**，否则外层计数会被破坏。

## 常见坑

::: warning 五个高频错误
1. **忘了 `ENDIF` / `NEXT` / `ENDWHILE`**：报"未闭合"，位置常指向文件末尾
2. **`WHILE` 忘了改条件变量**：死循环
3. **`GOSUB` 后忘了 `RETURN`**：一路执行下去，跳不回来
4. **主程序末尾忘写 `END`**：子程序被多执行一次，数量翻倍
5. **内外循环用同一个变量名**：结果错乱，极难查
:::
