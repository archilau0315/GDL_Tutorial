# 第 2 章 变换堆栈

> 图号 GDL-02 · 入门篇 · 阅读约 25 分钟 · 含沙盒练习

## 本章目标

- 理解「变换是**移动整张坐标系**，不是移动物体」
- 掌握 `ADD` / `ROT` / `MUL` / `DEL` 四个核心变换
- 养成 `ADD` 与 `DEL` 成对出现的习惯
- 能预判「先转后移」与「先移后转」的差异

## 心法：你搬的是坐标系，不是房子

这是 GDL 最容易误解、也最关键的一点：

> `ADD` 不是把一个物体挪走，而是**把整个坐标系（原点 + 三个轴的方向）挪走**。之后画的所有东西都长在新原点上。

想象你在图纸上画图：`ADD 1, 0, 0` 相当于把整张纸向右推 1 米，然后你在新的纸原点继续画。**已经画好的东西不会跟着动**，后面的才会。

## 四个核心变换

| 命令 | 作用 | 常见用途 |
|---|---|---|
| `ADD x, y, z` | 平移原点 | 摆位置 |
| `ROT x, y, z` | 依次绕 X、Y、Z 轴旋转（度） | 阵列、斜撑、旋转体 |
| `MUL x, y, z` | 缩放坐标轴 | 做变体、局部拉伸 |
| `DEL n` | 撤销最近 n 次变换 | 回到上一层坐标系 |

`DEL` 是**栈操作**：每次 `ADD`/`ROT`/`MUL` 都往栈上压一层，`DEL 1` 弹出一层，`DEL 2` 弹两层，`DEL TOP` 一次弹干净。

::: warning 变换是累积的
```gdl
ADD 0, 0, 0.4
BLOCK 1, 0.6, 0.05
ADD 0, 0, 0.4
BLOCK 1, 0.6, 0.05
```
第二块板在 **0.8** 的高度，不是 0.4——因为第二次 `ADD` 是在已经抬高的坐标系上再抬 0.4。这是初学阶段最容易"莫名漂移"的原因。
:::

## 对比实验：加不加 DEL

下面沙盒里两段循环**逐字相同**：都是「按 `i*45` 转一下、走出去 0.9m、画一块板」。唯一区别是右边每轮多写了 `DEL 2`。

- **左边**：不 DEL，`ROTZ i*45` 的转角一轮轮往上叠（45°、90°、135°…），距离也跟着累积——块全散开，位置互相重叠
- **右边**：每轮 `DEL 2` 回到起点重新出发，按真实角度摆一圈，得到规整的圆环

<GdlPlayground preset="stack" :height="460" />

只差这一句 `DEL 2`，几何完全失控。**看模型比看代码更快理解栈。**

::: tip 为什么左边会"转飞"
`ROTZ i*45` 里的 `i*45` 是**绝对角度**，可 `ROT` 是**相对叠加**的：第一轮转 45°，第二轮在这个基础上又转 90°（累计 135°），第三轮再转 135°（累计 270°）。角度叠歪了，块自然越摆越乱。有了 `DEL 2`，每轮都从 0° 起算，`i*45` 才是你想要的那个角度。
:::

## 单轴快捷命令

`ADD x, y, z` 要写三个参数，其实 GDL 提供了单轴版本，读起来更清楚：

| 快捷写法 | 等价于 |
|---|---|
| `ADDX 1.5` | `ADD 1.5, 0, 0` |
| `ADDY 1.5` | `ADD 0, 1.5, 0` |
| `ADDZ 0.9` | `ADD 0, 0, 0.9` |
| `ROTX 90` / `ROTY 90` / `ROTZ 90` | 绕单轴旋转 |
| `MULX 2` / `MULY 2` / `MULZ 2` | 单轴缩放 |

新手建议：**能用单轴就用单轴**，代码意图一目了然，也不容易把参数写错位置。

## 顺序问题：先转还是先移

变换按书写顺序依次叠加到坐标系上，所以顺序决定结果：

```gdl
! 写法 A：先移到 1.5 处，再绕自己转
ADD 1.5, 0, 0
ROTZ 45
BLOCK 0.3, 0.1, 0.6

! 写法 B：先转坐标系，再沿转后的 X 轴走出去
ROTZ 45
ADD 1.5, 0, 0
BLOCK 0.3, 0.1, 0.6
```

A 里物体在 (1.5, 0) 原地转；B 里物体沿着 45° 方向走出去 1.5 米。**两者位置不同**。

判断方法：变换只影响**它之后**的命令，且后写的变换建立在**前面变换后的坐标系**上。

## 阵列：栈 + 循环的经典组合

```gdl
FOR i = 1 TO 8
  ROTZ i * 45          ! 转坐标系
  ADD 1.5, 0, 0        ! 沿转后的 X 轴走出去
  BLOCK 0.3, 0.1, 0.6  ! 画一个
  DEL 2                ! 两层都退掉，回到原点
NEXT i
```

`DEL 2` 把 `ROTZ` 和 `ADD` 一起弹掉。**循环里每次都要回到相同的起点**，否则误差会累积——这是阵列代码必须成对 `DEL` 的原因。

## 常见坑

::: warning 四个高频错误
1. **`DEL` 数量不对**：压了两层只退一层，下一轮循环的起点就偏了
2. **在错误层级画东西**：`ROT` 之后忘了画完再 `DEL`，导致后续所有内容都被转
3. **以为 `ROT` 是绕物体中心转**：它绕的是**当前坐标系原点**
4. **`MUL` 用负数**：镜像会造成面法线翻转，Archicad 里可能显示异常
:::
