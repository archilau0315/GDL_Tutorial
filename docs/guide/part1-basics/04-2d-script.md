# 第 4 章 2D 脚本

> 图号 GDL-04 · 入门篇 · 阅读约 25 分钟 · 含沙盒练习

## 本章目标

- 理解 2D 脚本与 3D 脚本的分工
- 掌握六个常用 2D 绘图命令及其**参数陷阱**
- 会用 `POLY2_` 的 `frame_fill` 位控制轮廓与填充
- 知道 `PROJECT2` 是什么、什么时候该用

## 2D 脚本管什么

3D 脚本管模型，**2D 脚本管平面图上看到的样子**。两者互不干扰：

- 平面图上摆一把椅子，你看到的是 2D 脚本画出的符号，不是模型投影
- 2D 脚本为空时，Archicad 用对象里存的二进制符号（老式做法，不建议）
- 复杂对象做 2D 符号比投影快得多，也更符合制图习惯

::: tip 单位与坐标
2D 脚本的坐标也是米，**Y 轴向上**（与 3D 的 X/Y 平面一致）。原点同样是对象插入点。
:::

## 六个命令

```gdl
LINE2   x1, y1, x2, y2           ! 直线：两点
RECT2   x1, y1, x2, y2           ! 矩形：两个对角点
CIRCLE2 x, y, r                  ! 圆：圆心 + 半径
ARC2    x, y, r, a1, a2          ! 圆弧：圆心、半径、起止角（度）
POLY2   n, frame_fill, x1,y1, ...! 多边形：n 个顶点
TEXT2   x, y, "文字"              ! 文本：位置 + 字符串
```

## 三个必须记住的陷阱

::: warning 参数形态最容易错
1. **`RECT2` 是对角点，不是「x, y, 宽, 高」**
   `RECT2 0, 0, 1.2, 0.6` = 从 (0,0) 到 (1.2,0.6) 的矩形。写成宽高会得到诡异的尺寸。

2. **`CIRCLE2` 带圆心坐标**
   `CIRCLE2 0.5, 0.5, 0.1` = 圆心在 (0.5, 0.5)、半径 0.1。不是「半径 + 位置」。

3. **`TEXT2` 第三参必须是字符串**
   文字要加引号：`TEXT2 0, 0, "450x450"`。不加引号会被当成变量名。
:::

## POLY2 与 POLY2_：轮廓与填充

`POLY2` 只给顶点坐标：

```gdl
POLY2 4, 7, 0, 0, 1.2, 0, 1.2, 0.6, 0, 0.6
```

第二个参数 `frame_fill` 是**位组合**，决定画什么：

| 位 | 值 | 含义 |
|---|---|---|
| j1 | 1 | 画轮廓线 |
| j2 | 2 | 画填充 |
| j3 | 4 | 闭合多边形 |

`7 = 1+2+4` 就是「轮廓 + 填充 + 闭合」，最常用。**只要 1 就是只描边；只要 2 不闭合则不填充**。

`POLY2_`（带下划线）多一组状态位，每个顶点后跟一个 `s`：

```gdl
POLY2_ 4, 7, 0,0,1, 1.2,0,1, 1.2,0.6,1, 0,0.6,-1
```

- `s = 1`：从该顶点出发的下一段**可见**
- `s = 0`：该段**隐藏**（画填充但不要边线时很有用）
- `s = -1`：**轮廓结束**（闭合标记）

## 弧线：ARC2 的起止角

`ARC2 x, y, r, a1, a2` 从 `a1` **逆时针**画到 `a2`，角度单位是度：

```gdl
ARC2 0, 0, 0.5, 0, 90      ! 从正东逆时针画到正北（四分之一圆）
ARC2 0, 0, 0.5, 0, 270     ! 四分之三圆
```

逆时针为正，所以画下半圆要写 `180 → 360`，不是 `0 → -180`。

## 2D 变换：ADD2 / ROT2 / MUL2 / DEL2

2D 有自己独立的变换栈，命令名带 `2`：

```gdl
ADD2 0.5, 0      ! 平移原点（2D）
ROT2 30          ! 旋转坐标系（度）
MUL2 2, 1        ! 缩放
DEL2 1           ! 退回一层
```

**与 3D 栈互不影响**：`ADD 5,5,5` 不会让 2D 图形跑掉。沙盒里可以验证这一点。

## PROJECT2：把 3D 投影到平面

```gdl
PROJECT2 3, 270, 2
```

意思是「用 3D 模型在某个方向的投影作为平面符号」。三个参数分别是投影方式、方位角、显示选项。

**什么时候用**：形状复杂、平面符号就是俯视图时（如异形家具）。**什么时候不用**：需要制图规范化符号时（门窗、洁具），手绘 2D 更清楚。

::: warning 沙盒限制
沙盒不执行投影计算，`PROJECT2` 会被忽略。学这一句是为了在 Archicad 里能用，练手请用手绘 2D 命令。
:::

## 常见坑

::: warning 四个高频错误
1. **`RECT2` 当宽高用**：得到位置和尺寸都不对的结果
2. **`POLY2` 顶点数写错**：`n` 与实际坐标个数不符，报参数错误
3. **忘了闭合**：`frame_fill` 没有 4 位，填充不出现
4. **用 3D 变换改 2D**：`ADD` 对 2D 图形无效，必须用 `ADD2`
:::
