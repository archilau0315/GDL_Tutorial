# 第 15 章 REQUEST 与 GLOB

> 图号 GDL-15 · 精通篇 · 阅读约 30 分钟 · 含沙盒练习

## 本章目标

- 分清哪些值来自参数、哪些来自项目环境（`GLOB_*`）
- 用 `GLOB_SCALE` / `GLOB_ID` / `GLOB_HSTORY_ELEV` 做「跟着项目走」的对象
- 用 `SYMB_POS_X/Y/Z` 和 `GLOB_WORLD_ORIGO_OFFSET_*` 处理定位
- 用 `REQUEST` 函数查询字体样式等运行时信息

## 两种「外部数据」

前 14 章的脚本都是自给自足：参数进来，几何出去。真实项目里对象必须知道自己在哪、在什么比例下显示、属于哪一层——这些值由 Archicad 注入，统称全局变量。

| 来源 | 写法 | 谁给的 | 典型用途 |
|---|---|---|---|
| 参数 | `w`、`h` | 用户 / 参数表 | 尺寸、开关 |
| 全局变量 | `GLOB_SCALE` | Archicad 项目环境 | 按出图比例缩放、判断视图 |
| 函数查询 | `REQUEST(...)` | 运行时数据 | 字体高度、关联库部件参数 |

全局变量是**只读**的，赋值会报错；它们也不像变换栈那样在宏调用时保存/恢复。

## 常用 GLOB 速查

| 变量 | 含义 | 类型 |
|---|---|---|
| `GLOB_SCALE` | 当前图比例（100 = 1:100） | 数值 |
| `GLOB_ID` | 元素 ID 字符串 | 字符串 |
| `GLOB_HSTORY_ELEV` | 所在楼层标高 | 长度 |
| `GLOB_N_STORIES` | 项目楼层总数 | 数值 |
| `GLOB_FRAME_NR` | 当前帧号（动画/多帧对象） | 数值 |
| `SYMB_POS_X` / `Y` / `Z` | 对象自身的放置点坐标 | 长度 |
| `GLOB_WORLD_ORIGO_OFFSET_X` / `Y` | 世界原点相对项目的偏移 | 长度 |

完整清单（几百个，含视图、幕墙、MEP 专用）见官方 GDL Reference 的 Global Variables 一章。名字记不住就在官方页面按关键词搜，别猜。

::: warning 全局变量有脚本类型限制
视图相关、项目相关的全局变量**不能**写在参数脚本里。参数脚本会在切换视图时反复执行，读到不同的值会让同一个对象的参数变来变去，Archicad 会给出 GDL 警告，并用一个类型默认值代替。
:::

## 示例 1：按出图比例缩放标注

```gdl
! 2D 脚本：文字大小随图比例变化，1:100 时 2.5 mm 字高
paperH = 0.0025                    ! 图纸上的字高（米）
modelH = paperH * GLOB_SCALE      ! 换算到模型空间
TEXT2 0, 0, "SCALE 1:" + STR (GLOB_SCALE, 1, 0)
ADD2 0, modelH * 2
TEXT2 0, 0, "1000"
DEL2 1
```

`GLOB_SCALE` 是整数比例值：1:100 时等于 100。**模型空间里所有几何都按真实尺寸写**，只有需要「纸上看起来固定大小」的东西（字高、符号、标注箭头）才乘 `GLOB_SCALE`。

## 示例 2：把元素 ID 写进对象

```gdl
! 2D 脚本：元素 ID 变了，标注跟着变
IF GLOB_ID <> "" THEN
  elemID = GLOB_ID
ELSE
  elemID = "未编号"
ENDIF
TEXT2 0, -0.15, elemID
```

对象被复制、重新编号后，`GLOB_ID` 会跟着变，标注自动同步——这正是「不要手写文字」的理由（第 11 章的老问题）。

## REQUEST：向 Archicad 要数据

`REQUEST` 不是命令语句，是**函数**，返回值是成功填进去的变量个数：

```gdl
n = REQUEST ("Height_of_style", "Arial", hStyle)
```

| 部分 | 含义 |
|---|---|
| `"Height_of_style"` | 请求类型（字符串，固定写法） |
| `"Arial"` | 输入：样式名 |
| `hStyle` | 输出变量，单位毫米 |
| `n` | 返回 1 表示成功，0 表示没拿到 |

常见用途：按文字样式算标注框高度、读取关联库部件的参数、把对象信息写进属性。请求类型很多而且逐个有专属参数表，**不要凭记忆写**，用的时候查官方 REQUEST 条目。

::: warning 沙盒暂未支持 GLOB 与 REQUEST
沙盒没有项目环境，`GLOB_*` 和 `REQUEST` 都会报未定义。本章代码块是**结构与写法示意**，请在 Archicad 里验证；沙盒演示用写死的比例值代替 `GLOB_SCALE`，逻辑完全一样。
:::

## 常见坑

::: warning 三个高频错误
1. **在参数脚本里读 `GLOB_SCALE`**：参数脚本不允许视图相关变量，会得到警告和假值
2. **把 `GLOB_SCALE` 乘到所有几何上**：模型会变成 100 倍大；只有「纸面尺寸」才乘
3. **`REQUEST` 当命令用**：写成 `REQUEST "Height_of_style", ...` 不合法，必须 `n = REQUEST(...)`
:::

## 练习

1. 做一个「比例尺」2D 符号：画一条 1 米长的线，旁边标注 `1:50`、`1:100` 时都能正确显示实际长度。
2. 用 `GLOB_HSTORY_ELEV` 在 3D 里把对象底面标高打印成文字，验证它读的是楼层标高而不是绝对高度。

::: details 参考答案 1
```gdl
! 2D 脚本
LINE2 0, 0, 1.0, 0                  ! 模型里 1 米
LINE2 0, -0.02, 0, 0.02
LINE2 1.0, -0.02, 1.0, 0.02
TEXT2 0.05, -0.10, "1 m  @  1:" + STR (GLOB_SCALE, 1, 0)
```
线段长度始终是 1 米（模型尺寸），只有文字位置和字高需要按比例调。
:::

::: details 参考答案 2
```gdl
! 2D 脚本：把楼层标高当文字打出来
TEXT2 0, -0.2, "elev = " + STR (GLOB_HSTORY_ELEV, 8, 3)
```
读到的值已经是长度单位（米），不要再乘 1000；`STR` 只负责格式化显示。要在 3D 里验证，改成把文字放在 `ADD 0, 0, GLOB_HSTORY_ELEV` 之后即可。
:::
