# 第 18 章 毕业实战：门窗对象交付

> 图号 GDL-18 · 精通篇 · 阅读约 40 分钟 · 含沙盒练习

## 本章目标

- 把一句「做一个单开门」变成可验收的需求书与参数表
- 按 3D → 2D → 热区 → 界面的顺序，写出能交付的完整对象
- 用一张验收清单自检，而不是等同事来报 bug
- 知道交付物到底包含哪些文件

## 需求书：先把话说清楚

| 项目 | 要求 | 验收方式 |
|---|---|---|
| 洞口 | 宽 `A`、高 `B`，可自由输入 | 改参数，模型跟着变 |
| 门框 | 宽 50 mm，进深跟随墙厚 `wallT` | 侧视图量厚度 |
| 门扇 | 厚度 40 mm，四周留 3 mm 缝 | 3D 放大看缝隙 |
| 开启方向 | 左开 / 右开，2D 弧线跟着翻 | 平面图检查 |
| 把手 | 内外各一个，高 1.0 m | 3D 检查 |
| 平面符号 | 门洞 + 门扇 + 90° 弧 + 尺寸标注 | 平面 1:50 |
| 编辑 | 拖顶边改 `B`，拖侧边改 `A` | 平面拖动测试 |
| 信息 | 元素 ID 与尺寸写进 2D 文字 | 复制对象后文字自动变 |

一句「做个门」到这里才算可执行。**参数表就是需求书的代码版**。

## 参数表

| 变量名 | 描述名 | 类型 | 默认值 |
|---|---|---|---|
| `A` | 洞口宽 | Length | 1.00 |
| `B` | 洞口高 | Length | 2.10 |
| `wallT` | 墙厚 | Length | 0.20 |
| `ft` | 框宽 | Length | 0.05 |
| `lt` | 扇厚 | Length | 0.04 |
| `swing` | 右开 | Boolean | 0 |
| `matFrame` | 框材质 | Material | 3 |
| `matLeaf` | 扇材质 | Material | 1 |

参数脚本守住下限，避免出现负尺寸：

```gdl
! 参数脚本
VALUES "A" 0.60, 2.40, 0.05
VALUES "B" 1.80, 2.60, 0.05
VALUES "wallT" 0.10, 0.50, 0.01
VALUES "ft" 0.03, 0.10, 0.005
IF A < 0.9 THEN
  PARAMETERS ft = 0.04            ! 窄门自动减框宽
ENDIF
```

## 第一步：3D 脚本

```gdl
! === 单开门 3D / single door ===
! 门框：两根立梃 + 一根上槛，进深跟随墙厚
MATERIAL matFrame
BLOCK ft, wallT, B
ADD A - ft, 0, 0
BLOCK ft, wallT, B
DEL 1
ADD 0, 0, B - ft
BLOCK A, wallT, ft
DEL 1

! 门扇：贴在洞口内侧，左右各留 3 mm
MATERIAL matLeaf
ADD ft + 0.003, (wallT - lt) / 2, 0.003
BLOCK A - 2 * ft - 0.006, lt, B - ft - 0.006
DEL 1

! 把手：内外各一个，高 1.0 m
MATERIAL 6
ADD A - ft - 0.12, -0.03, 1.00
BLOCK 0.025, 0.05, 0.025
ADD 0, wallT + 0.01, 0
BLOCK 0.025, 0.05, 0.025
DEL 2
```

三处坐标值得停一下：门扇的 Y 用 `(wallT - lt) / 2` 自动居中，墙厚改了不用动；把手用 `A - ft - 0.12` 贴在门扇边缘；最后 `DEL 2` 把两次 `ADD` 一起退回。

## 第二步：2D 脚本

```gdl
! === 平面符号 / plan symbol ===
LINE2 0, 0, A, 0                    ! 洞口线
LINE2 0, wallT, A, wallT            ! 另一侧墙面
LINE2 0, 0, 0, wallT
LINE2 A, 0, A, wallT

! 门扇 + 开启弧（90°）
LINE2 0, 0, 0, A
ARC2 0, 0, A, 0, 90

! 尺寸与编号
TEXT2 0.02, -0.12, "D " + STR (A, 4, 2) + " x " + STR (B, 4, 2)
TEXT2 0.02, -0.26, GLOB_ID
```

`GLOB_ID` 让编号跟着元素走（第 15 章）。要左右开切换，就加一个 `IF swing THEN`，把弧线画到另一侧——2D 是最容易看出方向对不对的地方。

## 第三步：热区与界面

```gdl
! 2D 脚本追加：拖侧边改 A，拖顶边改 B
HOTSPOT2 0, 0, 1, A, 1 + 128        ! A 的基准点
HOTSPOT2 -0.1, 0, 2, A, 3           ! 参考点，决定 +X 为正
HOTSPOT2 A, 0, 3, A, 2              ! A 的移动点
HOTSPOT2 0, wallT, 4, B, 1 + 128    ! B 的基准点
HOTSPOT2 0, -0.1, 5, B, 3
HOTSPOT2 0, B, 6, B, 2
```

界面按第 13 章的三层结构，把 8 个参数分两页：

```gdl
UI_DIALOG "门 / Door", 320, 220
UI_PAGE "尺寸 / Size"
  UI_OUTFIELD "洞口宽", 10, 10, 70, 20
  UI_INFIELD  "A",     85, 10, 90, 20
  UI_OUTFIELD "洞口高", 10, 40, 70, 20
  UI_INFIELD  "B",     85, 40, 90, 20
UI_PAGE "构造 / Build"
  UI_OUTFIELD "墙厚", 10, 10, 70, 20
  UI_INFIELD  "wallT", 85, 10, 90, 20
  UI_CHECKBOX "右开", 10, 45, 120, 20
```

## 第四步：验收清单

| 检查项 | 怎么做 | 合格标准 |
|---|---|---|
| 尺寸联动 | 改 `A` / `B` | 框、扇、把手全部跟着动，没有悬空件 |
| 墙厚变化 | `wallT` 从 0.1 改到 0.5 | 框进深跟着变，门扇仍居中 |
| 极值 | `A = 0.6`、`B = 2.6` | 不出现负尺寸、不穿模 |
| 平面表现 | 1:50 / 1:100 各看一次 | 弧线完整，文字不压线 |
| 拖动 | 拖侧边与顶边 | 参数跟着变，放开后不回弹 |
| 复制 | 复制一份并重新编号 | 2D 文字自动更新 |
| 清单 | 出一次明细表 | 尺寸字段有值，不是空白 |
| 性能 | 放 50 个在平面里 | 平移缩放不卡 |

## 常见坑

::: warning 三个高频错误
1. **门扇贴死门框**：留 3 mm 缝，否则 3D 里出现共面闪烁
2. **`DEL` 少退一层**：把手画到了下一个对象的位置，越往后越偏
3. **2D 弧线方向没跟开向**：平面图上看不出左右开，现场装反
:::

## 练习

1. 把门改成双开：中间加中缝，两扇各占一半，`swing` 控制先开哪一扇。
2. 给门加一条 2D 门槛线，并在 3D 里加 20 mm 高的门槛石。

::: details 参考答案 1
```gdl
! 3D：两扇各占一半，中缝 4 mm
half = (A - 2 * ft - 0.004) / 2
MATERIAL matLeaf
ADD ft + 0.003, (wallT - lt) / 2, 0.003
BLOCK half, lt, B - ft - 0.006
ADD half + 0.004, 0, 0
BLOCK half, lt, B - ft - 0.006
DEL 2
```
中缝宽度写进 `half` 的公式里，改 `A` 时两扇自动重算。
:::

::: details 参考答案 2
```gdl
! 3D：门槛石
MATERIAL 5
ADD 0, 0, -0.02
BLOCK A, wallT, 0.02
DEL 1

! 2D：门槛线
LINE2 0, 0, A, 0
```
门槛石在 `z = 0` 以下，注意别和楼板共面；2D 门槛线与洞口线重合即可，别画成两条。
:::
