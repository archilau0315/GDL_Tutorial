# 第 10 章 门窗对象

> 图号 GDL-10 · 进阶篇 · 阅读约 20 分钟 · 含沙盒练习

## 本章目标

- 说清门窗对象由哪几部分组成
- 知道 `A`、`B`、`ZZYZX` 在门窗模板里的大致角色
- 会画符合制图习惯的门、窗平面符号
- 明白墙体洞口必须在 Archicad 里验证，沙盒不模拟宿主墙

## 门窗不是普通家具

家具是独立形体；门窗要**嵌进墙里**，还要在墙上切出洞口。这带来四个额外要求：

| 要求 | 说明 |
|---|---|
| 随墙厚变化 | 换一面更厚的墙，框和洞口要跟着变 |
| 自动切洞 | 插入后墙体不能还留着一块实心 |
| 平面符号规范 | 门要有门扇和开启弧，窗要有框和玻璃线 |
| 可替换子部件 | 门扇、把手、玻璃能单独换，不必重做整个对象 |

## 对象的组成

| 组成 | 作用 | 在哪编辑 |
|---|---|---|
| 参数面板 | 宽、高、墙厚、开启方向、材质等 | 对象设置 |
| 3D 脚本 | 生成框、扇、玻璃、五金 | 3D 脚本页 |
| 2D 脚本 | 画平面符号 | 2D 脚本页 |
| 墙体洞口 wallhole | 定义在宿主墙上切出的轮廓 | 洞口组件 / 洞口脚本 |
| 子上下文 subcontext | 把门扇、框、把手拆成可单独替换的子部件 | 子部件编辑 |

### 关于 A、B、ZZYZX

| 参数 | 门窗模板里的常见含义 | 注意 |
|---|---|---|
| `A` | 洞口名义宽度 | 2D 符号和洞口宽度都应以它为准 |
| `B` | 洞口名义高度 | 门扇、窗扇高度的基准 |
| `ZZYZX` | 深度方向参数，常表示墙厚 | 不同模板含义可能不同，以参数面板说明为准 |

::: warning 洞口不是用 BLOCK 挖出来的
墙体洞口由对象的洞口组件/洞口脚本定义轮廓，再由 Archicad 在宿主墙上生成，不是“画一个负的 BLOCK”。洞口命令与参数签名随版本、模板变化，本文不给出未核实的写法，请查官方手册的 Wallhole 章节。
:::

### 设计顺序

1. 定参数：洞口宽 `A`、高 `B`、墙厚
2. 画 3D 主形体：框 → 扇 → 玻璃 → 五金
3. 定义洞口轮廓，确保与参数算出的尺寸一致
4. 画 2D 符号：洞口边线、扇、开启弧、标注
5. 拆子上下文、接材质
6. 插入真实墙体验证：切洞、翻转、换墙厚

## 示例一：单扇门平面符号（可运行）

墙沿 X 方向，厚度 `t` 在 Y 方向，洞口从 `x = 0` 到 `x = w`，铰链在左侧：

```gdl
w = 0.9         ! 洞口宽
t = 0.24        ! 墙厚
leaf = 0.045    ! 门扇厚

! 洞口两侧墙垛
RECT2 -0.6, 0, 0, t
RECT2 w, 0, w + 0.6, t

! 洞口边线（门垛内侧）
LINE2 0, 0, 0, t
LINE2 w, 0, w, t

! 门扇：绕左侧铰链开到 90°
RECT2 0, t, leaf, t + w

! 开启弧：圆心在铰链，半径等于洞口宽
ARC2 0, t, w, 0, 90

! 标注
TEXT2 -0.55, t + 0.1, "M900"
```

墙垛表示墙体断开，`LINE2` 是洞口边线，`RECT2` 是开着的门扇，`ARC2` 是开启轨迹。四样齐了，读图的人才知道门往哪边开、开多大。

## 示例二：单扇窗平面符号（可运行）

窗比门少一条开启弧，多框和玻璃线：

```gdl
w = 1.2
t = 0.24

! 墙垛与洞口边线
RECT2 -0.5, 0, 0, t
RECT2 w, 0, w + 0.5, t
LINE2 0, 0, 0, t
LINE2 w, 0, w, t

! 窗框：洞口内缩 60mm
RECT2 0.06, 0.06, w - 0.06, t - 0.06

! 玻璃：墙厚中间画双线
LINE2 0.06, t / 2 - 0.015, w - 0.06, t / 2 - 0.015
LINE2 0.06, t / 2 + 0.015, w - 0.06, t / 2 + 0.015

TEXT2 -0.45, t + 0.1, "C1200"
```

重点是“洞口 + 框 + 玻璃”三层关系，尺寸都从 `w`、`t` 推出来，改参数才不会错位。

## 试一试：门窗平面符号

沙盒的 `plan` 预设是一张桌子的平面符号。清空编辑器，把示例一的代码整段粘进去，就能看到门的符号。改两处观察联动：

<GdlPlayground preset="plan" :height="460" />

1. `w = 0.9` 改成 `1.2`：洞口、门扇、开启弧一起变
2. `t = 0.24` 改成 `0.12`：墙垛和框变薄

沙盒不模拟宿主墙，所以这里验证的是**符号画法**，不是洞口。

## 常见坑

::: warning 三个高频错误
1. **把门窗当普通家具**：只写 3D 形体、不定义洞口，插入墙后墙上仍是实心的
2. **2D 符号写死尺寸**：`RECT2 0, 0, 0.9, 0.24` 改 `A` 或墙厚后立刻错位，坐标都应由 `w`、`t` 推导
3. **在沙盒里验证切洞**：沙盒不模拟宿主墙、不开洞、不跟随墙厚，只能在 Archicad 插真实墙体验证
:::

## 练习

**练习 1**：把示例一改成双扇门，洞口宽 `w = 1.5`，两扇各占一半。

::: details 答案
两扇门各有一条开启弧，右侧铰链在 `x = w`：

```gdl
w = 1.5
t = 0.24
leaf = 0.045
half = w / 2

RECT2 -0.6, 0, 0, t
RECT2 w, 0, w + 0.6, t
LINE2 0, 0, 0, t
LINE2 w, 0, w, t

! 左扇
RECT2 0, t, leaf, t + half
ARC2 0, t, half, 0, 90

! 右扇
RECT2 w - leaf, t, w, t + half
ARC2 w, t, half, 90, 180

TEXT2 -0.55, t + 0.1, "M1500"
```

右侧弧写成 `90, 180` 才是 90° 的四分之一圆；写成 `180, 90` 会被算成 270°，画成四分之三圆。
:::

**练习 2**：给示例二的窗加一根竖向中挺，把玻璃分成左右两格。

::: details 答案
在玻璃线之后加一条竖线，位置取洞口中心：

```gdl
! 接在示例二的玻璃线之后
LINE2 w / 2, 0.06, w / 2, t - 0.06
```

顺序是：墙垛 → 洞口边线 → 窗框 → 两条玻璃线 → 中挺 → 标注。中挺从框的内边到内边，不要画进墙垛。
:::
