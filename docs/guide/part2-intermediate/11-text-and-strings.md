# 第 11 章 文本与字符串

> 图号 GDL-11 · 进阶篇 · 阅读约 20 分钟 · 含沙盒练习

## 本章目标

- 会用 `TEXT2 x, y, "文字"` 在平面符号上写标注
- 掌握字符串的三条硬规则：双引号、中文直写、引号转义
- 分得清「2D 文本」和「参数标签」分别出现在哪里
- 知道 `STR` / `STRLEN` / 拆分与拼接的用途，也清楚沙盒的边界

## 概念：两种「文字」

同样叫「文字」，在对象里的位置完全不同：

| 对比 | 2D 文本 `TEXT2` | 参数标签 |
|---|---|---|
| 归属 | 2D 脚本 / 平面符号 | 对象参数（宽 `w`、深 `d`…） |
| 出现在 | 平面图、图纸、打印 | 对象设置对话框、清单/明细表 |
| 谁生成 | GDL 画出的一条文字图元 | Archicad 读取参数定义后显示 |
| 参与几何 | 否，只是标注 | 否，是数据 |
| 典型用途 | 编号、尺寸、房间名 | 参数说明、清单列 |

一句话：**平面图上看得见的字，是 `TEXT2` 画出来的；参数面板里的字，是 Archicad 读取参数定义后显示的。** 两者互不替代。

### 字符串的三条规则

1. **必须用双引号**：`"CABINET"` 是字符串，`CABINET` 会被当成变量名
2. **中文、空格、符号直接写**：`"柜体 1200 x 600"` 没问题，不需要转义
3. **字符串里的引号写两个**：`""` 表示一个双引号（沙盒按 GDL 惯例处理）

::: tip 沙盒里的 TEXT2 只有三个参数
`TEXT2 x, y, "文字"`：前两参是 2D 坐标（米），第三参是字符串。沙盒按文字左侧基线放置；字高、对齐等样式在 Archicad 里另有设置，需在本机验证。
:::

## 分步示例 1：最小文本

```gdl
! 只有文字，没有几何 / text only
TEXT2 0, 0, "CABINET"
TEXT2 0, -0.12, "1200 x 600"
TEXT2 0.02, 0.10, "中文标注也可以"
```

运行后 3D 视口是空的，右侧 2D 视口出现三行字。这说明：**`TEXT2` 属于 2D 脚本，不会生成模型。**

## 分步示例 2：给平面加尺寸标注

```gdl
! 2D 标注：轮廓 + 尺寸线 + 文字
w = 1.20
d = 0.60

RECT2 0, 0, w, d

! 下方尺寸线：主线 + 两端竖短线
LINE2 0, -0.12, w, -0.12
LINE2 0, -0.16, 0, -0.08
LINE2 w, -0.16, w, -0.08

! 文字位置可以用变量算，内容必须是字面量
TEXT2 w / 2 - 0.15, -0.28, "1200"
TEXT2 0.02, d + 0.08, "PLAN 1:50"
TEXT2 0.02, d / 2, "柜体 / CABINET"
```

三件事值得注意：

- `RECT2` 用两个对角点，`LINE2` 用两组端点，单位都是米
- 文字位置能跟着 `w` / `d` 变，**文字内容不会**
- 把 `w` 改成 `2.40`，轮廓和尺寸线会变长，但 `"1200"` 仍然是 1200——这就是没有字符串拼接的代价

## 字符串函数：知道用途就够了

字符串处理在真实对象里很常见：编号 `"CAB-001"`、规格 `"1200x600x750"`、把参数按分隔符拆开。GDL 提供了对应能力，但它们**不在沙盒白名单里**：

| 需求 | GDL 能力 | 典型用途 | 沙盒 |
|---|---|---|---|
| 数字转文本 | `STR` 一类 | 把宽度拼进编号 | ✗ |
| 取字符串长度 | `STRLEN` 一类 | 校验编号位数 | ✗ |
| 按分隔符拆分 | `SPLIT` 一类 | 拆 `"1200x600x750"` | ✗ |
| 拼接 | 字符串连接 | 生成规格标签 | ✗ |

::: warning 沙盒暂不支持字符串函数
本章不给出这些函数的具体参数顺序——不同版本写法有差异，写错比不写更误导。**需要时在 Archicad 内查 GDL 参考并试跑验证**；沙盒里请把文字写成字面量。
:::

## 常见坑

::: warning 三个高频错误
1. **忘了双引号**：`TEXT2 0, 0, CABINET` 会把 `CABINET` 当变量，报「变量未定义」
2. **想用 `+` 拼字符串**：`"W" + w` 在沙盒里是数值加法，会报「不是数字」；拼接要用字符串能力，沙盒不支持
3. **把 `TEXT2` 当参数标签**：参数标签在对象设置和清单里，`TEXT2` 只画在平面图上；改了参数，文字不会自动更新
:::

## 练习

1. 给 1.2 × 0.6 的柜体平面加三条标注：顶部名称、下方总宽、右侧总深，并在尺寸线两端加短线。
2. 用 `ADD2` + `ROT2` 在四个方向各写一个 `"H"`，观察文字位置如何随变换栈变化。

::: details 参考答案 1
```gdl
w = 1.20
d = 0.60

RECT2 0, 0, w, d

! 下方总宽
LINE2 0, -0.12, w, -0.12
LINE2 0, -0.16, 0, -0.08
LINE2 w, -0.16, w, -0.08

! 右侧总深
LINE2 w + 0.12, 0, w + 0.12, d
LINE2 w + 0.08, 0, w + 0.16, 0
LINE2 w + 0.08, d, w + 0.16, d

TEXT2 0.02, d + 0.08, "BASE CABINET"
TEXT2 w / 2 - 0.15, -0.28, "1200"
TEXT2 w + 0.20, d / 2, "600"
```
:::

::: details 参考答案 2
```gdl
FOR i = 1 TO 4
  ADD2 0.60, 0.30     ! 移到中心
  ROT2 i * 90         ! 每个方向转 90°
  TEXT2 0.35, 0, "H"
  DEL2 2
NEXT i
```
文字和几何一样受 2D 变换栈控制，四个 `"H"` 会分别落在上、左、下、右四个方向。注意沙盒只变换文字位置，不旋转字形；Archicad 里的文字角度行为需在本机验证。
:::
