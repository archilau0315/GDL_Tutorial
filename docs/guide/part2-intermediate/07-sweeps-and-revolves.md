# 第 7 章 旋转与放样

> 图号 GDL-07 · 进阶篇 · 阅读约 20 分钟 · 含沙盒练习

## 本章目标

- 用 `REVOLVE` 把轮廓绕 X 轴转成实体
- 用 `EXTRUDE` 沿任意方向挤出，理解 `mask` 的作用
- 分清 PRISM / EXTRUDE / REVOLVE 三者的适用边界
- 知道 `RULED` / `SWEEP` / `TUBE` 各自做什么、什么时候该换它们

## 三种成型方式

前两章的 PRISM 只会「直上直下」。真实构件常常要斜着长、或者转着长：

| 方式 | 轮廓怎么动 | 典型构件 |
|---|---|---|
| `PRISM` | 沿 +Z 直推 | 异形柱、型材 |
| `EXTRUDE` | 沿任意向量推 | 斜撑、雨棚、坡道 |
| `REVOLVE` | 绕 X 轴旋转 | 花瓶、柱头、圆环 |

记住一句话：**PRISM 定方向，EXTRUDE 定向量，REVOLVE 定轴**。

## REVOLVE：让截面转起来

```gdl
REVOLVE n, alpha, mask, x1,y1,s1, x2,y2,s2, ..., xn,yn,sn
```

| 参数 | 含义 |
|---|---|
| `n` | 顶点个数，与后面三元组数量一致 |
| `alpha` | 旋转角度（度），不能为 0；`360` 表示一整周 |
| `mask` | 位掩码，控制哪些面生成（沙盒忽略，全部生成） |
| `x`, `y` | 截面顶点，**在 x-y 平面上** |
| `s` | 状态码，规则同 PRISM：`1` / `0` / `-1` |

最关键的一条：**`y` 就是旋转半径**，必须 ≥ 0。`y = 0` 表示顶点落在轴上、实体在此收口；`y = 0.3` 就是离轴 0.3m。`x` 则是沿轴方向的位置。

`y < 0`、`alpha = 0` 都会报错；沙盒里 `alpha` 不到 360 时，两端会自动补封盖。

::: tip 轴线默认是横的
REVOLVE 绕 **X 轴**旋转，所以生成物天然「躺」在 X 方向上。要做竖立的柱子或花瓶，先 `ROT 0, 90, 0` 把轴立起来，画完再 `DEL 1`。
:::

## 示例 1：一根圆柱

矩形截面绕轴转一圈就是圆柱：

```gdl
ROT 0, 90, 0
REVOLVE 4, 360, 0,
  0,    0.00, 1,
  0,    0.30, 0,
  1.00, 0.30, 0,
  1.00, 0.00, -1
DEL 1
```

四个点：轴上起点、半径 0.3、半径 0.3 走 1m、轴上收口。`alpha = 360` 生成完整圆柱面，不需要端盖。

## 示例 2：花瓶（多段轮廓）

把半径按高度分段（0.12 → 0.16 → 0.16 → 0.10 → 0），就能做出瓶底、鼓腹、收颈的曲线感：

```gdl
MATERIAL 6
ROT 0, 90, 0
REVOLVE 6, 360, 0,
  0.00, 0.00, 1,
  0.00, 0.12, 0,
  0.06, 0.16, 0,
  0.22, 0.16, 0,
  0.30, 0.10, 0,
  0.30, 0.00, -1
DEL 1
```

注意起点和终点都在 `y = 0`，实体两端才能封死；中间点 `y > 0`，才有壁厚。

## EXTRUDE：沿任意向量挤出

```gdl
EXTRUDE n, dx, dy, dz, mask, x1,y1,s1, x2,y2,s2, ..., xn,yn,sn
```

| 参数 | 含义 |
|---|---|
| `n` | 顶点个数 |
| `dx`, `dy`, `dz` | 挤出向量，长度和方向都由它决定 |
| `mask` | 位掩码，控制端面 / 侧面是否生成（沙盒忽略） |
| `x`, `y`, `s` | 截面顶点与状态码，规则同 PRISM |

两条硬规则：**零向量报错**（`dx = dy = dz = 0` 没有体积）；**`mask` 的位含义以官方手册为准**，沙盒一律全部生成，看不到差异。

## 示例 3：斜向雨棚

```gdl
MATERIAL 3
EXTRUDE 4, 1.0, 0, 0.45, 0,
  0,   0,   1,
  1.2, 0,   0,
  1.2, 0.6, 0,
  0,   0.6, -1
```

截面是 1.2 × 0.6 的矩形，但挤出向量带着 `dz = 0.45`，所以越往前越高。换成 PRISM 就只能得到水平的板——这就是两者的本质区别。

## RULED / SWEEP / TUBE

| 命令 | 做什么 | 与 EXTRUDE / REVOLVE 的区别 |
|---|---|---|
| `RULED` | 在两个不同轮廓之间连面 | 两端截面可以不同，EXTRUDE 只能同截面平移 |
| `SWEEP` | 让轮廓沿一条路径扫过 | 路径可以弯，REVOLVE 只能绕直轴转 |
| `TUBE` | 圆截面沿路径成管 | 专做管线、弯头，比 SWEEP 少写轮廓 |

选型顺序：直推 `PRISM` → 斜推 `EXTRUDE` → 绕轴 `REVOLVE` → 截面渐变 `RULED` → 沿弯路径 `SWEEP` / `TUBE`。

::: warning 沙盒暂未支持，也不要在参数上猜
`RULED` / `SWEEP` / `TUBE` 在沙盒里暂未实现，参数较多且版本有差异，本章不给签名。使用时请查 Graphisoft 官方 GDL Reference，不要照抄论坛片段。
:::

## 常见坑

::: warning 三个高频错误
1. **`REVOLVE` 的 `y` 写成负数**：`y` 是半径不是坐标，负值直接报错
2. **`alpha = 0` 或挤出向量为零**：没有体积，运行时报错
3. **忘了先把轴立起来**：REVOLVE 默认绕 X 轴，不 `ROT` 就是横躺的构件
:::

## 练习

1. 用 `REVOLVE` 做一个 270° 的弧形靠背：内半径 0.25、外半径 0.45、宽 0.8。
2. 用 `EXTRUDE` 做一根 45° 斜撑：截面 0.1 × 0.1，沿 X 和 Z 各走 0.8。

::: details 参考答案 1：270° 弧形靠背

```gdl
ROT 0, 90, 0
REVOLVE 4, 270, 0,
  0,    0.25, 1,
  0,    0.45, 0,
  0.80, 0.45, 0,
  0.80, 0.25, -1
DEL 1
```

:::

::: details 参考答案 2：45° 斜撑

```gdl
EXTRUDE 4, 0.8, 0, 0.8, 0,
  0,   0,   1,
  0.1, 0,   0,
  0.1, 0.1, 0,
  0,   0.1, -1
```

:::
