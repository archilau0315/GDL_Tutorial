# 第 8 章 材质与属性

> 图号 GDL-08 · 进阶篇 · 阅读约 20 分钟 · 含沙盒练习

## 本章目标

- 分清**材质**（表面）与**画笔**（线条）各自管什么
- 会用 `MATERIAL n`、`PEN n` 指定数值索引
- 理解索引指向“项目表里的位置”，不是固定颜色
- 避开两个顺序陷阱：先设后用、`DEL` 不还原

## 材质与画笔

`MATERIAL` 和 `PEN` 都不画东西，它们只改“当前状态”：

| 命令 | 管什么 | 写法 | 影响谁 |
|---|---|---|---|
| `MATERIAL n` | 3D 实体的表面材质 | `MATERIAL 8` | 之后的 3D 形状 |
| `PEN n` | 线条使用的画笔 | `PEN 2` | 之后的轮廓与 2D 线 |

两个命令都只接受**一个数值索引**。写 `MATERIAL "Wood"`、`PEN "Red"` 都会报错，颜色名在 GDL 里不是合法参数。

::: tip 材质与画笔是两套表
材质表管“表面是什么材料”，画笔表管“线用哪支笔、多粗”。同一块木板可以有木质材质，同时用细笔画轮廓。不要指望改 `MATERIAL` 会顺带改线条颜色。
:::

## 索引不是颜色

在真实 Archicad 里，`MATERIAL 8` 的含义是“当前项目材质表中的 8 号材质”。它可能是“砖-红”，也可能在另一个项目里是“混凝土”。换模板、换专业、合并图层，编号对应的材料都可能变。

1. 不要把索引当颜色常量背下来
2. 交付对象时在注释里写清“8 = 木饰面”，并附项目材质表说明
3. 换项目后先抽查几个索引，再批量套用

| 索引 | 沙盒近似色 | 常见用途（仅示意） |
|---|---|---|
| 0 | 默认蓝 | 未设置材质时 |
| 3 | 棕 | 木作、门扇 |
| 4 | 浅棕 | 饰面、家具 |
| 8 | 橙 | 强调、台面 |

::: warning 沙盒颜色与 Archicad 不一致
沙盒没有材质表，只有一套固定的 **13 色**调色板：索引对 13 取余后取色，0 号是默认蓝。上表只是“看起来大概是什么色”，**不能**当作 Archicad 材质表的对照。沙盒只帮你区分“这块和那块不是同一种材质”；`PEN` 只检查参数个数，不改变线条显示。
:::

## 示例一：给桌面和桌腿分配材质

顺序很重要：每条 `MATERIAL` 放在对应几何之前。

```gdl
! 桌面：8 号；桌腿：3 号
MATERIAL 8
ADD 0, 0, 0.7
BLOCK 1.2, 0.6, 0.04
DEL 1

MATERIAL 3
FOR i = 1 TO 2
  FOR j = 1 TO 2
    ADD 0.05 + (i - 1) * 1.1, 0.05 + (j - 1) * 0.5, 0
    CYLIND 0.7, 0.03
    DEL 1
  NEXT j
NEXT i
```

循环里只设一次 `MATERIAL 3`，四条腿都会变——因为它是状态，会一直保留到下一次设置。

## 示例二：先设后用，`DEL` 不还原

```gdl
MATERIAL 8
BLOCK 1, 0.4, 0.1

ADD 0, 0.5, 0
BLOCK 1, 0.4, 0.1        ! 仍是 8 号

ADD 0, 0.5, 0
MATERIAL 4
BLOCK 1, 0.4, 0.1        ! 只有这一块是 4 号

ADD 0, 0.5, 0
BLOCK 1, 0.4, 0.1        ! 还是 4 号：DEL 不会把材质退回去
DEL 3
```

- 材质设置**不会追溯**已经画好的形状
- `DEL` 只回退坐标变换，不回退材质和画笔
- 想“恢复”旧材质，必须再写一次 `MATERIAL`

## 示例三：循环里按条件换材质

抽屉面板一深一浅，用奇偶判断即可：

```gdl
FOR i = 1 TO 4
  IF i / 2 = INT(i / 2) THEN
    MATERIAL 4
  ELSE
    MATERIAL 8
  ENDIF
  ADD 0, 0, i * 0.18
  BLOCK 0.6, 0.03, 0.14
  DEL 1
NEXT i
```

`INT(i / 2)` 与 `i / 2` 相等，说明 `i` 是偶数。这个写法只用基础函数，沙盒和 Archicad 都能跑。

## 试一试：给书架换材质

预设是一个参数化书架，所有板件都用默认色。运行前改三处：

1. 在“两侧立板”之前插入 `MATERIAL 3`
2. 在层板 `WHILE` 循环之前插入 `MATERIAL 8`
3. 在“顶板”之前插入 `MATERIAL 4`

## 常见坑

::: warning 三个高频错误
1. **先画后设**：`BLOCK` 已经生成，再写 `MATERIAL 3` 对它没有任何作用，材质只影响之后的形状
2. **以为 `DEL` 会还原**：`DEL` 弹的是变换栈，不是属性栈，子程序改的材质会带回主程序
3. **跨项目照搬索引**：A 项目 8 号是木饰面，B 项目可能变成玻璃，换项目必须重新核对
:::

## 练习

**练习 1**：让书架的层板一深一浅交替，仍用 `WHILE` 循环。

::: details 答案
引入计数器 `k`，每画一层加一，用奇偶切换材质：

```gdl
! 接在书架预设的 w / d / h / th 之后
z = 0
k = 0
WHILE z <= h - th
  IF k / 2 = INT(k / 2) THEN
    MATERIAL 4
  ELSE
    MATERIAL 8
  ENDIF
  ADD 0, 0, z
  BLOCK w, d, th
  DEL 1
  z = z + 0.4
  k = k + 1        ! 必须自增，否则材质不变
ENDWHILE
```
:::

**练习 2**：下面两行想给同一个柜体上色，为什么都报错？怎么改？

```gdl
! 错误示例：颜色名不是合法参数
MATERIAL "Wood"
PEN Red
```

::: details 答案
`"Wood"` 是字符串，`Red` 会被当成未定义变量；两个命令都只接受数值索引。改成当前项目材质表/画笔表里的编号：

```gdl
MATERIAL 3
PEN 2
```
:::
