# 第 6 章 PRISM 全家族

> 图号 GDL-06 · 进阶篇 · 阅读约 20 分钟 · 含沙盒练习

## 本章目标

- 读懂 `PRISM` 的顶点表，把任意多边形截面一次挤出
- 分清状态码 `1` / `0` / `-1` 的作用
- 知道 `PRISM_` 与 `CPRISM_` / `BPRISM_` / `FPRISM_` / `SPRISM_` 各解决什么问题
- 能判断什么时候该用 PRISM、什么时候用 BLOCK 或 CYLIND 更省事

## 一句话理解

`BLOCK` 只能做长方体，`CYLIND` 只能做圆柱；要让柱子是 L 形、T 形、六边形，用 `PRISM`：**给一串平面顶点，沿 Z 轴拉出高度**。

## 语法：三段结构

```gdl
PRISM n, h, x1,y1,s1, x2,y2,s2, ..., xn,yn,sn
```

| 参数 | 含义 |
|---|---|
| `n` | 顶点个数（≥3），必须与后面三元组的数量一致 |
| `h` | 挤出高度，沿 +Z |
| `x`, `y` | 顶点在**当前坐标系** x-y 平面上的坐标（米） |
| `s` | 状态码：`1` 首点、`0` 中间点、`-1` 末点 |

状态码不是装饰：Archicad 靠 `1 ... 0 ... -1` 判断轮廓从哪开始、在哪闭合，缺首尾状态码会报错或几何错乱。

::: tip 顶点要按顺序走一圈
沿轮廓边界依次排列，**不要交叉**。交叉的轮廓（像数字 8）在 Archicad 里会自交报错，在沙盒里也可能出现乱面。
:::

## 示例 1：先做三角形柱

```gdl
PRISM 3, 1.5,
  0,   0,   1,
  1.2, 0,   0,
  0,   0.9, -1
```

三个顶点、三个状态码、高度 1.5m。截面自动闭合，**不需要重复写首点**。

## 示例 2：L 形柱

L 形要 6 个点，按顺序走一圈：

| 序号 | x | y | 状态码 | 位置说明 |
|---|---|---|---|---|
| 1 | 0 | 0 | `1` | 起点（内角） |
| 2 | 0.6 | 0 | `0` | 沿 X 向右 |
| 3 | 0.6 | 0.2 | `0` | 上折 |
| 4 | 0.2 | 0.2 | `0` | 向左回 |
| 5 | 0.2 | 0.6 | `0` | 再向上 |
| 6 | 0 | 0.6 | `-1` | 收口 |

```gdl
ADD 0, 0, 0
PRISM 6, 1.2,
  0,   0,   1,
  0.6, 0,   0,
  0.6, 0.2, 0,
  0.2, 0.2, 0,
  0.2, 0.6, 0,
  0,   0.6, -1
DEL 1
```

`ADD 0, 0, 0` 加 `DEL 1` 看着多余，其实是习惯：真实代码里 PRISM 常和别的构件并排，先把基准钉住，以后改位置只动 `ADD` 那一行。

## 示例 3：一个截面，多个高度

```gdl
x = 0
FOR i = 1 TO 2
  h = 0.4 + (i - 1) * 0.8
  ADD x, 0, 0
  PRISM 4, h,
    0,   0,   1,
    0.5, 0,   0,
    0.5, 0.3, 0,
    0,   0.3, -1
  DEL 1
  x = x + 0.8
NEXT i
```

同一个截面换个 `h`，就是两种型材。参数化对象的雏形就在这里：**顶点表负责形状，变量负责尺寸**。

## PRISM_ 与四个变体

它们都基于「轮廓 + 高度」，差别在**轮廓怎么给**：

| 命令 | 用途 | 轮廓来源 |
|---|---|---|
| `PRISM_` | 多轮廓、带洞口（如带孔板） | 顶点表按状态码分段 |
| `CPRISM_` | 端面为圆弧切削的棱柱 | 截面 + 圆弧参数 |
| `BPRISM_` | 上下端面可控的棱柱 | 截面 + 端面控制 |
| `FPRISM_` | 沿参考面变化的棱柱 | 截面 + 参考面 |
| `SPRISM_` | 竖向轮廓 + 侧向轮廓 | 两组轮廓 |

::: warning 沙盒只支持单轮廓
沙盒对 `PRISM_` 只按**单轮廓**处理（单轮廓可以正常运行），多轮廓和洞口不会生效。想验证洞口效果，请在 Archicad 里测试。
:::

`CPRISM_` / `BPRISM_` / `FPRISM_` / `SPRISM_` 的参数多、版本差异也大，本章只要求记住「什么时候会想到它」，**具体签名以 Graphisoft 官方 GDL Reference 为准**，不要凭记忆写。

## 什么时候别用 PRISM

矩形用 `BLOCK`，圆用 `CYLIND`，斜向挤出用 `EXTRUDE`，绕轴用 `REVOLVE`——PRISM 只负责「平面异形轮廓 + 直上直下」。

## 常见坑

::: warning 三个高频错误
1. **`n` 与顶点组数不一致**：写 `PRISM 6` 却只给 5 组点，直接报参数个数错误
2. **状态码全写 `0`**：首尾没有 `1` / `-1`，Archicad 无法确定轮廓边界
3. **顶点顺序交叉**：轮廓自交，几何翻面或直接报错
:::

## 练习

1. 把 L 形改成 **T 形柱**（8 个顶点），高度 0.9m，翼缘宽 0.6、腹板宽 0.2。
2. 用 `FOR` 排出 3 根六边形柱，间距 0.9m，高度依次为 0.4 / 0.8 / 1.2。

::: details 参考答案 1：T 形柱

```gdl
ADD 0, 0, 0
PRISM 8, 0.9,
  0,   0,   1,
  0.6, 0,   0,
  0.6, 0.2, 0,
  0.4, 0.2, 0,
  0.4, 0.5, 0,
  0.2, 0.5, 0,
  0.2, 0.2, 0,
  0,   0.2, -1
DEL 1
```

:::

::: details 参考答案 2：三根六边形柱

```gdl
FOR i = 1 TO 3
  h = 0.4 * i
  ADD (i - 1) * 0.9, 0, 0
  PRISM 6, h,
     0.35,  0.000,  1,
     0.175, 0.303,  0,
    -0.175, 0.303,  0,
    -0.35,  0.000,  0,
    -0.175, -0.303, 0,
     0.175, -0.303, -1
  DEL 1
NEXT i
```

:::
