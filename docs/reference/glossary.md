# 术语对照表

GDL 的中文资料里，同一个概念常有几种叫法：有人把 hotspot 叫「热点」，有人叫「热区」；有人把 library part 叫「图库对象」，官方叫「图库部件」。查手册时对不上号，往往不是不会，而是名字没对齐。

这份对照表只收**最容易混淆**的那批术语，中英并列，给出英文原名与一句话解释。

## 怎么用

- 直接搜中文或英文都能命中，例如「热区」「hotspot」「gsm」
- 按用途分组：对象与图库、脚本与运行、几何与坐标、参数与界面、属性与材质、工具链与交付
- 每条右侧的「对应章节」可直接跳到讲这个概念的教程

## 三组最容易搞混的词

| 容易混 | 区别 |
|---|---|
| 材质 Material / 建筑材质 Building Material | 前者是渲染表面的颜色属性，后者带厚度与构造信息，用于墙体和复合结构 |
| 热区 Hotspot / 热点 | 是指同一个东西（HOTSPOT2），「热点」是早期译法，官方中文用「热区」 |
| 主脚本 Master Script / 参数脚本 Parameter Script | 主脚本负责传参与前置计算，参数脚本只在参数变化时运行 |

::: tip 数据单源双语
术语清单存放在 `reference/data/glossary.json`，中英字段并存一份，两个语言页面共用，修订只改数据不动页面。
:::

::: warning 译名不统一时以英文为准
遇到不同教材译法冲突，请以官方英文名为准，再回到本表核对。命令、参数、变量名一律保持英文原样，不要翻译。
:::
