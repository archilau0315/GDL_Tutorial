# 常见错误手册

报错信息 → 原因 → 改法。前半部分直接来自本站沙盒引擎，报错文字和你在编辑器里看到的**逐字一致**；后半部分是 Archicad 环境里最常见的四类问题。

## 先看三件事

1. **报错行号是提示，不是判决**：语法块类错误（IF/FOR/WHILE 未闭合）常常报在块尾，真正缺东西的是上面某一行
2. **先看第一个错误**：后面的错误往往是第一个的连锁反应，改完一个再跑一遍
3. **改一个数字再看一次**：报错消失但模型不对，说明语法没问题、几何逻辑有问题，回到对应章节对照参数
