# 资料库

GDL 资料库为「查」而设计：正在写脚本时，10 秒内找到命令用法。

## 入口

- [命令速查表](/reference/commands/) —— 沙盒已支持的全部 3D / 2D / 属性 / 控制流命令，可按关键词搜索与分类筛选
- [GLOB 变量速查](/reference/globals) —— 28 个常用全局变量，按用途分组，附最小示例与常见误传
- [代码片段库](/reference/snippets) —— 12 段可直接粘贴的常用写法，标注沙盒可运行与对应章节
- [常见错误手册](/reference/errors) —— 24 条报错与现象，按「原因 → 改法 → 错误/正确写法」对照
- [术语表](/reference/glossary) —— 39 个易混术语的中英对照，搜中文或英文都能命中

::: tip 数据单源双语
速查表数据存放在 `reference/data/*.json`，中英字段并存一份，中英文页面共用，修订只改数据不动页面。
:::
