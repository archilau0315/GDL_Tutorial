# Chapter 1 Your First 3D Object

> Sheet GDL-01 · Part 1 Basics · content under construction (full text and sandbox land in phases P1/P2)

In this chapter you will build a parametric stool with the four primitives `BLOCK`, `CYLIND`, `SPHERE`, `CONE` and the fixed parameters `A`, `B`, `ZZYZX`.

## Primitives at a Glance

```gdl
BLOCK 1, 2, 0.9      ! box: x × y × z
CYLIND 0.4, 1.2      ! cylinder: base radius × height
SPHERE 0.5           ! sphere: radius
CONE 0.5, 2, 0       ! cone: base radius × height × top radius
```
