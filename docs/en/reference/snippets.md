# Snippet Library

The pieces you retype most often, already split out: search, copy, paste into a library part, tweak two numbers.

- Snippets marked "runs in sandbox" can be pasted straight into the [playground](/en/playground/) to see the result
- The rest need Archicad (parameter scripts, file I/O, GLOB) — the sandbox does not emulate them
- Every snippet links to its chapter, so you can read the reasoning behind it
