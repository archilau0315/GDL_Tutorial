# Error Handbook

Message → cause → fix. The first half comes straight from the site sandbox engine, so the wording matches what you see in the editor; the second half covers the four most common Archicad environment issues.

## Read it this way

1. **The reported line is a hint, not a verdict** — block errors (unclosed IF/FOR/WHILE) are often reported at the end, while the real omission is a line above
2. **Fix the first error first** — later ones are usually knock-on effects; rerun after each fix
3. **Change one number, look again** — if the error clears but the model is wrong, the syntax is fine and the geometry logic needs a look
