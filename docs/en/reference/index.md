# Command Index

The reference library is built for lookup: find how a command works within 10 seconds while you are writing a script.

## Entries

- [Command Index](/en/reference/commands/) — all 3D / 2D / attribute / control commands, grouped by category (under construction)
- GLOB variable tables (planned)
- Snippet library (planned)
- Error handbook (planned)

::: tip Single bilingual data source
Reference data lives in `reference/data/*.json` with both `desc_zh` and `desc_en` fields in one file, shared by the Chinese and English pages — update data only, never pages.
:::
